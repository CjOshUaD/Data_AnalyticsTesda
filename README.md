## About

This repository contains basic 20 SQL queries for the TESDA
Data Analytics Level III training program. Queries practice
SELECT, FROM, and WHERE on two tables: employees and products.

## Database

Queries run against Day04_practice.db (SQLite). The database
is excluded from this repository (see .gitignore). Reviewers
can download it from the course LMS.

## Files

- CSV_file/employees_csv - 10 csv files that contains results of the queries
- CSV_file/products_csv - 10 csv files that contains results of the queries
- queries/employees_queries.sql — 10 queries on the employees table
- queries/products_queries.sql — 10 queries on the products table

## Tools

VS Code + SQLTools extension + SQLTools SQLite driver
